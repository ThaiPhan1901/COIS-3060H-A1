Explore Mining Software Repositories

Find data, choose collection and analysis techniques, and discover publication venues for empirical software engineering research.

01 / FIND DATA

Data Sources

Common sources of evidence about software development, collaboration, and project outcomes.

SourceData providedDescription
GitHubRepositories, commits, pull requests, issues, starsHosts source code and collaboration histories useful for studying development activity, code review, and project evolution.
Stack OverflowQuestions, answers, tags, user reputationCommunity question-and-answer data can support research on developer knowledge sharing and problem solving.
JIRAIssues, sprint data, bug reportsIssue-tracking records help researchers examine task management, defect resolution, and agile workflows.
App Stores
Google Play and Apple App Store		Reviews, ratings, downloads (availability varies)App-store data supports studies of user feedback, perceived quality, and app popularity. Access and available fields vary by store and collection method.
Travis CI / JenkinsBuild logs, test results, deployment dataContinuous integration records can be used to investigate build failures, testing practices, and delivery pipelines.
Mailing ListsDeveloper discussions and archivesArchived conversations provide qualitative evidence about design decisions, coordination, and community practices.
npm RegistryPackage dependencies, downloads, versionsPackage metadata supports research on dependency networks, package evolution, and ecosystem health.

02 / GATHER EVIDENCE

Collection Methods

Choose a collection approach based on the source, scale, reproducibility, and data access rules.

MethodWhat it is used forAdvantagesLimitations
REST APIsStructured requests to services such as GitHub and Stack Overflow.Structured responses; documented endpoints; usually easier to automate.Rate limits, authentication requirements, and endpoint-specific data limits.
GraphQLFlexible queries, such as selecting related GitHub objects and specific fields.Fetches selected fields in a request; can reduce unnecessary data transfer.Query complexity limits, pagination, and a learning curve.
Web Scraping — SeleniumAutomating browser interaction and collecting dynamic pages when permitted.Can interact with JavaScript-rendered content and browser workflows.Slower and more fragile; site changes can break scripts; respect terms and robots policies.
Web Scraping — BeautifulSoupParsing HTML pages, especially static pages that have already been retrieved.Lightweight and straightforward for extracting structured elements from HTML.Does not execute JavaScript; page layout changes can break selectors.
Database Dumps
GHTorrent, SOTorrent		Large-scale or historical repository and community data.Useful for bulk analysis and repeatable research on a fixed snapshot.May be dated, large to store, incomplete, or costly to process.
Manual DownloadOne-time datasets and CSV exports.Easy for small studies; minimal code required.Hard to repeat at scale; manual steps can introduce errors and become outdated.

Good practice: record the collection date, query or script, API version where relevant, inclusion criteria, and known missing data.

03 / MAKE SENSE OF DATA

Analysis Methods

Match the method to the research question and the structure and quality of the evidence.

MethodType of analysisCommon use cases
Statistical AnalysisDescriptive statistics, hypothesis testing, correlationSummarize repository characteristics, compare groups, and assess relationships between variables.
Regression AnalysisLinear regression, logistic regression, prediction modelsEstimate associations or predict outcomes such as defect-proneness or review duration.
Thematic AnalysisQualitative coding and theme identificationIdentify recurring themes in developer discussions, issue reports, interviews, or review comments.
Grounded TheorySystematic qualitative analysis with iterative codingDevelop concepts or theory from qualitative evidence when existing explanations are limited.
Machine LearningClassification, clustering, neural networksClassify defects, group projects, detect patterns, or build predictive models.
Time Series AnalysisTrend analysis, seasonality, forecastingStudy how commits, issue activity, downloads, or build failures change over time.
Network AnalysisGraph structure and network measuresExplore developer collaboration, co-editing networks, and package dependency graphs.
VisualizationPlots, heatmaps, dashboardsCommunicate distributions, comparisons, trends, and relationships; often complements other methods.
